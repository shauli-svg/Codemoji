# CodeMoji X — Product Source of Truth

CodeMoji is not a website.

CodeMoji is a tiny secret object that travels through chat and opens with a sign.

```text
Receive secret → draw sign → reveal → send one back
```

## V1 Rules

- No landing page.
- No login.
- No backend.
- No database.
- No raw URL as the primary UI.
- No technical copy.
- No plaintext in URL.
- No key in URL.
- Pattern derives the unlock key.
- Receiver-first when a capsule exists.

## Current vertical slice

Compose → CM8P capsule → Share → Receive → Draw pattern → Reveal → Reply.
